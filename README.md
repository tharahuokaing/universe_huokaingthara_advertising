## 🎯 About the Platform / អំពីវេទិកា

**UNIVERSE HUOKAING THARA Advertising Portal** is a centralized commercial management portal designed to connect brands, sponsors, and business partners with the multi-million view entertainment network led by **Huokaing Thara**. It provides a streamlined interface for reviewing performance metrics, selecting advertising tiers, and submitting campaign requests.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **📊 Live Metric Highlights:** Displays total monthly impressions ($100\text{M}+$ views), content channel distribution, and engagement metrics.
* **💳 Interactive Rate Cards:** Clear breakdown of Standard, Premium, and Enterprise sponsorship packages with feature comparison lists.
* **📝 Automated Client Form:** Client-side inquiry submission system for brand name, package selection, and custom campaign requirements.
* **🌐 Dual Language Support:** Instant toggle between **Khmer (ខ្មែរ)** and **English** interface presentations.
* **🌙 Dark/Light Theme Switcher:** Fully customizable cyberpunk visual styling with responsive UI support across mobile and desktop viewports.

## 🚀 Getting Started / ការចាប់ផ្តើម

To run this repository locally on your machine:

1. **Clone the repository:**

2. **Navigate to the project directory:**

3. **Open `index.html**` in any modern web browser or run it via VS Code Live Server
